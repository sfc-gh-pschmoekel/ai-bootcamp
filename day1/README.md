# Day 1: Build the Semantic Layer

**Topics:** Semantic Views, Cortex Search, Cortex AI Functions

## Run it
1. Download [`Saturday_Ops_Day1.ipynb`](Saturday_Ops_Day1.ipynb).
2. In Snowsight, go to **Projects > Workspaces > + Add > Upload Files**, and select the notebook.
3. Select a warehouse and click **Run all**. It takes about 5 minutes on an XS warehouse.

## What you will learn

| Section | Feature | Business unit |
|---|---|---|
| 1 | Generate 13 tables (structured and text) in one SQL cell | All |
| 2 | `AI_SENTIMENT`, `AI_CLASSIFY`, `AI_EXTRACT`, `AI_SUMMARIZE_AGG` | Fan Experience, Football Ops |
| 3 | Semantic View with metrics, synonyms, custom instructions and verified queries | Ticketing, Concessions and Merch, Development |
| 4 | Cortex Search over coach press conferences | Football Ops |
| 5 | Structured and unstructured data together | All |
